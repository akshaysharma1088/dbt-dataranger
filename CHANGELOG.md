# Changelog

## 0.1.0 (2026-11-14)

- `dataranger.reconciles_with_source` test: a model's rows and amounts per day, and optionally per segment, against the raw table it was built from.
- `dataranger.matches_control_totals` test: the same check against a control totals table.
- `dataranger.control_totals` macro: builds control totals from a raw table, in the layout DataRanger reads.
